Give a flattened TOML file its layout back

Paste the damaged file on the left and a well-formatted one in the middle: the values come from the first, the layout from the second. Without a template the file is simply reformatted — comments missing from the source cannot be invented. npm · source

What the template restores: comments, key order, blank lines, indentation, the column of aligned = signs, sections against inline tables, string style and number notation.

What it cannot do: update a comment describing a value you changed, or invent a comment for a key the template does not hold.

This page runs the published package, unbundled: it imports the same dist/ files npm install delivers.
